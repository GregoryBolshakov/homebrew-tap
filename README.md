# Homebrew tap

Homebrew formulas for my tools.

```
brew install gregorybolshakov/tap/peekme
```

| Formula | What it is |
|---|---|
| [peekme](https://github.com/GregoryBolshakov/peekme) | Select text in Codex CLI or Claude Code output and get a short explanation right under it, inside the terminal |

The formulas are updated by the release workflow of each tool.
